# dither-core

These files are part of the `dither-core` engine from dithercn
(https://dithercn.dev, source at https://github.com/opencoredev/dithercn),
MIT licensed; see LICENSE beside them. They are copied unchanged from the
registry item https://dithercn.dev/r/dither-core.json. Quill keeps only the
files the shader needs (shader, motion, color, glsl, matrices, blue-noise,
tokens) and uses them to draw the Dither recording pill. Import from
`@/lib/dither/shader` and `@/lib/dither/motion`; the package index is not
included.
